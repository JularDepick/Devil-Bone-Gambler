# 管理员手册

## 打开面板

- 按 Shift 加 D, 键位可以在控制界面改绑
- 或在游戏菜单的模组列表里选中本模组点配置按钮, 与按 Shift 加 D 完全等价
- 或执行 /devilbonegambler config, 短名 /dbgr config 等价
- 只有创建者与管理员能打开, 其他人按键没有反应

## 面板总览

- 顶部页签是奖池配置与祭品价值
- 上部编辑字段, 下部是表格: 表头冻结, 列宽固定, 过长内容裁切, 悬停可看全
- 滚动条可拖动, 状态行显示上一次操作的结果

## 奖池配置

- 表格列是区域, 条目名称, 权重, 颜色
- 新增区域会加一个区域, 区域编号对应骰子点数; 删除选中会连同该区域的条目一起删掉
- 新增条目在当前区域下加一行, 字段为区域编号, 条目名称, 权重, 颜色, 是否重大事件, 是否启用, 指令文本, 展示文本
- 条目名称就是一个字符串: 预设名称在生成配置时按当时的游戏语言写入, 之后不再随语言变化
- 权重越大越容易被抽到; 红色为正面, 黑色为负面
- 颜色, 重大事件与启用状态都是按钮, 点一下切换
- 指令文本可写多行, 每行一条原版指令, 开头的斜杠可以省略
- 支持占位符 ${player} 与 ${x} ${y} ${z}, 也支持 ${random:item} 这类随机令牌
- 指令校验不通过的条目不会被抽到, 状态行会说明原因
- 展示文本就是一个字符串, 只写奖品本身, 因为聊天框会显示 你获得了 s; 不要再写 你获得了 这类前缀, 也不会再出现翻译键或组件 JSON
- 展示文本留空时这条抽中后不显示提示

## 多选与删除

- 不按 Ctrl 点击为单选, 并清空之前的选择
- 按住 Ctrl 点击加入或移出选择, 最后点击的一行是主行
- 权重, 颜色, 重大事件, 启用, 指令文本与展示文本会写入全部选中条目
- 条目名称只写入主行
- 删除要点两次: 第一次只把文案换成确认, 在窗口内再点一次才真正删除; 超时或改动选择会恢复原状

## 祭品价值配置

- 表格列是名称与价值
- 祭品价值标签第一次点开这一页, 之后再点就在祭品价值, 物品价值与生物价值之间循环; 切换不会清空过滤框, 过滤框同时匹配名称与注册名
- 未登记的条目以弱化颜色显示, 悬停会说明原因
- 价值输入框在搜索框下方, 它下面的滑条与输入框显示同一个数: 滑条按整百大致拖动, 范围 0 到 100000, 输入框用于精确填写
- 填好的价值会写入全部选中条目

## 管理员名单

- 面板右上角的管理员按钮打开名单窗口, 其中列出创建者与全部管理员
- 只有创建者能增减管理员, 其他管理员只能查看
- 创建者不可被移除
- 输入玩家名字后点添加: 空输入, 重复的名字与创建者本人都被拒绝
- 名单改动对在线玩家立即生效, 离线玩家在下次进入时生效

## 荷官赌局的运维

- 一只荷官同一时间最多主持一场赌局, 招募一分钟
- 人数不足或发起者退出时赌局取消, 赌注与骰子全部退还
- 赌局进行中荷官被打死, 赌局中止并退还全部赌注与骰子, 玩家开着的荷官页面会自动关闭
- 荷官倒下会掉出背包里剩下的赌徒的骰子
- 招募开始几秒与开始前最后几秒有提示音, 便于判断节奏

## 提交与重载

- 提交把改动写盘; 修订号冲突时面板会载入最新配置, 再提交一次即可
- 保存失败时状态行给出原因
- 执行 /devilbonegambler reload(或 /dbgr reload)让服务端重新读取配置
- 这本手册跟随身份: 身份在就补发, 身份收回就一并收回; 丢弃后, 掉在地上的一本片刻后会消失并补回; 放进箱子等容器时, 关闭界面会回到背包

## 注意事项

- 除骰子点数那一行以外, 所有提示都进聊天框
- 指令按写下的内容原样执行, 改完先在单人存档里试一遍

## 模组指令占位符体系

- 指令里可以写 ^(类型) 或 ^(类型)[命名空间], 模组会在这个类型的样本空间里挑一个 ID 替换掉它
- 类型由模组在每次世界加载后从当前游戏内容自动识别, 结果写到配置目录的 sample_spaces.json, 换游戏版本或装新模组后只会更新这个文件, 不需要改源码
- 省略方括号时不限命名空间, 写了方括号就只在该命名空间里挑
- 黑红决定范围: 红点只在正面样本里挑, 黑点只在负面样本里挑, 该类型没有对应样本时回退到全部样本
- 点数与溢出越高, 越偏向样本空间里稀有的那部分; 运气越高也越偏向稀有与正面样本
- 通用类型: ITEM 物品, BLOCK 方块, ENTITY 实体类型, MOB 可生成的生物, EFFECT 状态效果, ENCHANTMENT 附魔, POTION 药水, SOUND 音效, PARTICLE 粒子, PAINTING 画, ATTRIBUTE 属性, FLUID 流体, BIOME 生物群系, STRUCTURE 结构, DAMAGE_TYPE 伤害类型
- 细分类型: BUFF 正面效果, DEBUFF 负面效果, NEUBUFF 中立效果, BUFF_ENCHANTMENT 正面附魔, CURSE 诅咒附魔, ENCHANTED_BOOK 直接给出一本带附魔的附魔书
- 一个指令行里可以写多个占位符, 每个各自独立抽一次
- 占位符只抽注册 ID, 不会在世界里生成实体或方块实例; 附魔书是唯一例外, 它直接给出一本带附魔的书
- 可以直接在聊天框试: /dbgr run <带占位符的指令>, 只有创建者与管理员能用
- 占位符里的 ID 只是在指令里替换成文本, 指令本身仍按原版语法执行, 改完先在单人存档里试一遍
- 抽中后, 抽中的样本名称会追加在展示文本后面, 用空格分隔; 没用占位符的条目不受影响
- 预设奖池共 6 个区域 604 条, 只在奖池文件不存在时生成; 已有存档保留原配置
