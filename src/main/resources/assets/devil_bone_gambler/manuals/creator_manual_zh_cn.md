# 创建者手册

## 创建者是谁

- 载入存档时, 如果管理访问配置里还没有创建者, 第一位进入服务器的玩家会被记录为创建者
- 创建者只会被记录一次, 之后不会改变
- 创建者不可被移除

## 创建者专属能力

- 打开管理面板: Shift 加 D, 或者命令 /devilbonegambler config
- 增减管理员名单
- 修改奖池配置与祭品价值配置

## 存档中的配置文件

- 奖池: <世界存档>/serverconfig/devil_bone_gambler/prize_pool.json
- 祭品价值: <世界存档>/serverconfig/devil_bone_gambler/item_values.json
- 随机池: <世界存档>/serverconfig/devil_bone_gambler/random_pools.json
- 管理访问: <世界存档>/serverconfig/devil_bone_gambler/access.json
- 修改前建议备份上述文件, 尤其是 access.json 与 prize_pool.json

## 手册发放

- 玩法手册: 每位玩家首次进入时发放
- 管理员手册: 管理员且不是创建者时, 首次进入时发放
- 创建者手册: 创建者首次进入时发放
- 三种手册每位玩家只发放一次, 且不可合成, 不可堆叠

# 管理员手册

## 打开面板

- 在游戏内按 Shift 加 D, 该键位可以在控制界面改绑
- 或者执行命令 /devilbonegambler config
- 只有创建者与管理员可以打开面板

## 奖池配置

- 列表是表格: 表头固定, 列宽固定, 内容过长会截断, 悬停可以看到完整内容
- 区域: 点击新增区域添加, 区域编号对应骰子点数
- 条目: 每行一个条目, 字段包括区域编号, 条目名称, 权重, 颜色, 是否重大事件, 是否启用, 指令与展示文本
- 条目名称只是给管理员区分条目的备注; 预设条目的名称跟随游戏语言
- 权重越大越容易被抽到; 颜色红色为正面, 黑色为负面
- 指令可以写多行, 每行一条原版指令, 开头的斜杠可以省略
- 指令支持 ${player} 与 ${x} ${y} ${z} 占位符, 也支持随机令牌 ${random:item}
- 指令校验不通过的条目不会被抽到, 状态行会给出原因
- 展示文本为空时使用默认文案

## 多选与删除

- 不按 Ctrl 点击一行是单选, 会清空之前的选择
- 按住 Ctrl 点击可以多选, 最后点击的一行是主行
- 修改权重, 颜色, 重大事件, 启用状态, 指令与展示文本会写入全部选中条目
- 条目名称只写入主行
- 删除按钮删除全部选中行, 第一次点击只把文案改为确认文案

## 祭品价值配置

- 表格两列: 名称与价值
- 顶部按钮循环切换全部, 祭品价值与生物价值三个章节
- 过滤框同时匹配名称与注册名
- 未登记的条目以弱化颜色显示, 悬停会说明原因
- 数值写入全部选中条目

## 管理员名单

- 只有创建者可以增减管理员
- 创建者不可被移除
- 输入玩家名字后点击添加; 空输入, 重复名字与创建者本人都会被拒绝

## 提交与保存

- 点击提交写盘
- 修订号冲突时面板会载入最新配置, 再次提交即可
- 保存失败时状态行给出失败原因

## 提示渠道

- 模组提示只进聊天框, 不占用物品栏上方
