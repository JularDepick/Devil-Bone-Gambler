一款 Minecraft 模组: 通过掷骰子触发随机奖励或惩罚。所有回报都取决于你的赌注和运气。

---

## 前置要求

| 项 | 要求 |
|:---:|:---:|
| Minecraft | 1.20.1 |
| 模组加载器 | Forge 47.4.23 |
| 前置模组 | 无第三方前置 |
| 安装位置 | 客户端与服务端都要安装 |

## 模组内容

### 物品与方块

| 名称 | 说明 |
|:---:|:---|
| 赌徒的骰子 | 右击抽取; 附近有其他玩家时潜行右击改为发起赌局 |
| 恶魔的骰子 | 右击抽取; 站在祭坛范围内右击改为打开献祭界面 |
| 恶魔的祭坛 | 放下的祭坛给范围内玩家力量; 也可以戴在头上, 等同在脚下放一座 |
| 祭品价值表 | 右击打开可搜索的价值表, 物品与生物两个章节 |
| 幸运苹果 | 八个赌徒的骰子围着一个苹果合成; 食用回满饱食度与生命值并授予 幸运之子 |
| 玩法手册 管理员手册 创建者手册 | 随包内容的三本书, 按身份发放, 不可合成 |
| 放置的骰子 | 按住放置键把骰子放到地上, 之后按着放置键挖回来, 不按键挖掘则等同于使用 |
| 赌徒的荷官生物蛋 | 生成一只荷官, 由骰子使用计数与创造模式物品页提供 |

### 状态效果

| 名称 | 说明 |
|:---:|:---|
| 幸运之子 | 食用幸运苹果后获得十秒, 期间幸运值锁定为 100, 结束后回到食用前的数值 |

## 玩法要点

- 骰子点数决定从奖池的哪个区域抽取, 点数高于区域编号时留下溢出值, 溢出越高越容易抽到该区域里少见的条目
- 颜色由幸运值换算: 红色点数只抽红色条目, 黑色点数只抽黑色条目, 因此颜色一公布就能大致判断结果
- 掷出后点数与颜色在快捷栏上方显示一行; 其余提示都进聊天框
- 潜行手持骰子时, 恶魔的骰子会标出附近的祭坛, 赌徒的骰子会标出附近的荷官
- 赌局是一段倒计时, 参与者在结算前不能使用赌徒的骰子; 荷官的赌局独立于玩家的赌局, 赌注由服务端托管
- 幸运值是 0 到 100 的隐藏数值, 显示在左上角并按区间变色, 会随时间与你的行为变化
- 同一祭坛范围内堆够八本玩法手册会被自动换成两种骰子
- 祭坛只有铁镐或更高等级的镐子能挖下, 爆炸与活塞都无法破坏

## 指令

| 指令 | 权限 | 说明 |
|:---:|:---:|:---:|
| `/devilbonegambler config` 或 `/dbgr config` | 创建者与管理员 | 打开配置面板 |
| `/devilbonegambler reload` 或 `/dbgr reload` | 创建者与管理员 | 重新读取配置文件 |
| `/devilbonegambler run <指令>` 或 `/dbgr run` | 创建者与管理员 | 在聊天框试跑带占位符的指令 |
| `/devilbonegambler luck <玩家> <数值>` 或 `/dbgr luck` | 创建者与管理员 | 把指定玩家的幸运值设为 0 到 100 内的值 |

游戏内按 Shift 加 D 也能打开配置面板, 键位可改绑

## 配置

奖池与祭品价值都在服务端配置文件的控制之下: 奖池可以并存多套, 按需切换; 条目的指令内容支持多行, 位置占位符, `%(n,m)` 随机整数, `--R(n)` 重复执行与样本空间占位符。运行期文件位置与配置项清单见 [开发者文档](./docs/developer/README.md)

## 兼容性

- 客户端与服务端都要是 0.7.0, 协议号不同时旧客户端会被服务端拒绝
- 奖池配置从 0.7.0 起改为多套并存的文件结构, 旧结构文件会被备份并改用内置的两套预设
- 幸运值是 0.7.0 新增的系统, 旧存档的玩家首次进入时从 80 点开始
